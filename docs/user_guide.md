# Dashboard User Guide — Drone Intelligence System for India

## Overview
The **Drone Intelligence System** dashboard provides 4 core workspaces:

### 1. 🤖 AI Chat Assistant Tab
- Ask questions regarding **DGCA Drone Rules 2021**, DigitalSky airspace permissions, or calculate flight endurance directly in conversation.
- Click **Quick Prompt Pills** to test pre-formulated queries.
- Expand **Sources & Citations** at the bottom of agent responses to inspect reference document snippets.

### 2. 🧮 Drone Calculators Tab (MCP Tools Suite)
- **Flight Time & Range**: Adjust sliders for battery capacity, payload, wind speed, and temperature. View power consumption charts.
- **Agriculture & Business ROI**: Simulate monthly revenue, net profit, payback period in months, and 3-year financial projections.
- **DGCA Compliance Checker**: Verify flight legality across Green, Yellow, and Red zones.
- **Drone Recommender**: Filter Indian drone models by budget and technical requirements.

### 3. 📁 Document Hub
- Drag & drop custom PDF/MD/TXT documents to ingest them into the vector database.

### 4. 📊 Analytics & Telemetry
- Monitor system query distributions, average latency, and flight telemetry data.
